# Errors

This page lists every error class exported from `pg-hybrid-rag`: where it is defined, what throws it, its fields, and whether a retry can help. It ends with the plain `Error` and `AggregateError` cases the library throws.

```ts
import {
  AttributeFiltersUnsupportedError,
  AttributeValidationError,
  EmbeddingApiError,
  EmbeddingResponseError,
  FilterModelApiError,
  FilterModelResponseError,
  FilterValidationError,
} from "pg-hybrid-rag";
```

All classes extend `Error` and set `name` to the class name, so `instanceof` and `err.name` both work.

| Class | Thrown by | Extra fields | Retry helps |
|-------|-----------|--------------|-------------|
| [`AttributeFiltersUnsupportedError`](#attributefiltersunsupportederror) | `RagPipeline`, `PostgresRagDatabase` | none | No |
| [`AttributeValidationError`](#attributevalidationerror) | `RagIndexer.index`, `normalizeAttributes` | `issues: string[]` | No |
| [`FilterValidationError`](#filtervalidationerror) | `RagPipeline.search`, `assertValidFilter` | `errors: string[]` | No |
| [`EmbeddingApiError`](#embeddingapierror) | `OpenAiCompatibleEmbedder` | `status: number` | For 429 and 5xx |
| [`EmbeddingResponseError`](#embeddingresponseerror) | `OpenAiCompatibleEmbedder` | none | No |
| [`FilterModelApiError`](#filtermodelapierror) | `OpenAiCompatibleFilterModel` | `status: number` | For 429 and 5xx |
| [`FilterModelResponseError`](#filtermodelresponseerror) | `OpenAiCompatibleFilterModel` | none | No |

## AttributeFiltersUnsupportedError

Module: `src/errors.ts`.

Thrown when an attribute filter is requested but the configured database or FTS strategy cannot apply it in every search leg. The library fails closed instead of returning rows the filter would have excluded.

Thrown by:

- `RagPipeline.search` / `searchWithDiagnostics`, before any embedding or database work, when `filter` is set or `autoFilter: true`, and `RagDatabase.supportsAttributeFilters` is not `true`. Default message: `Attribute filters are not supported by the configured database/FTS strategy`.
- `PostgresRagDatabase.hybridSearch`, when `params.attributeFilter` is set and the configured `FtsStrategy` does not set `supportsAttributeFilters: true`. The message says to set `supportsAttributeFilters = true` once the strategy applies `FtsContext.attributeFilter`.

Fields: `message`, `name`. The constructor takes an optional message.

Retry: no. Fix the configuration: use an adapter and FTS strategy that support filters (`PostgresRagDatabase` with `TsvectorFts` or `Bm25Fts` both do), or implement filtering in your custom one.

## AttributeValidationError

Module: `src/metadata/attributes.ts`.

Thrown by `normalizeAttributes`, and therefore by `RagIndexer.index` when `options.attributes` is invalid. `RagIndexer` validates attributes before calling the embedder, so no embedding cost is incurred and no rows change.

| Field | Type | Description |
|-------|------|-------------|
| `issues` | `string[]` | Every problem found, for example `attribute[0]: multi is only valid with enum` or `global.price: decimal value must be a decimal string`. |

`message` is `Invalid attributes: ` followed by the issues joined with `; `.

Retry: no. Correct the input. Rules are in [Filter grammar: Attributes](/reference/filter-grammar#attributes).

```ts
import { AttributeValidationError } from "pg-hybrid-rag";

try {
  await indexer.index("article", "7d0f1c2e-5b7a-4c1e-9a53-1f2e3d4c5b6a", chunks, "en", {
    attributes: [{ key: "launch", type: "date", value: "2026-02-30" }],
  });
} catch (err) {
  if (err instanceof AttributeValidationError) console.error(err.issues);
}
```

## FilterValidationError

Module: `src/metadata/filterSchema.ts`.

Thrown by `assertValidFilter`, and by `RagPipeline.search` / `searchWithDiagnostics` when the explicit `filter` option is invalid. The check runs before any embedding or database work.

| Field | Type | Description |
|-------|------|-------------|
| `errors` | `string[]` | Every problem found, each prefixed with its location, for example `$.and[1]: op "gt" is not allowed for type "boolean"`. |

`message` is `Invalid filter: ` followed by the errors joined with `; `.

A filter generated by `autoFilter` never throws this error. An invalid generated filter is dropped, and `SearchDiagnostics.generatedFilterStatus` is `"invalid"` with the messages in `generatedFilterErrors`.

Retry: no. Correct the filter. Rules are in [Filter grammar](/reference/filter-grammar).

## EmbeddingApiError

Module: `src/adapters/OpenAiCompatibleEmbedder.ts`.

Thrown by `OpenAiCompatibleEmbedder.embedQuery` and `embedDocuments` when the embeddings endpoint returns a non-2xx HTTP status.

| Field | Type | Description |
|-------|------|-------------|
| `status` | `number` | HTTP status code. |

`message` is `Embedding API error <status>: <response body>`.

Retry: the embedder already retries status 429 and 5xx up to `maxRetries` times (default 2) with exponential backoff, then throws. Other statuses (for example 400, 401, 404) are thrown on the first attempt. See [Embedder](/reference/embedder).

## EmbeddingResponseError

Module: `src/adapters/OpenAiCompatibleEmbedder.ts`.

Thrown when the endpoint returns a successful status but a body the embedder cannot use. Messages (after the `Embedding API response error: ` prefix):

- `` response is missing a `data` array ``
- `expected <n> embedding(s) but received <m>`
- `` an entry's `embedding` is not an array of finite numbers ``
- `` response `index` values are not a 0..n-1 permutation ``
- `response mixes indexed and non-indexed entries`

Fields: `message`, `name`.

Retry: no, and the embedder does not retry it. It indicates a misconfigured endpoint or a server that speaks a different protocol.

## FilterModelApiError

Module: `src/adapters/OpenAiCompatibleFilterModel.ts`.

Thrown by `OpenAiCompatibleFilterModel.generateFilter` when the chat completions endpoint returns a non-2xx HTTP status.

| Field | Type | Description |
|-------|------|-------------|
| `status` | `number` | HTTP status code. |

`message` is `Filter model API error <status>: <response body>`.

Retry: the filter model retries status 429 and 5xx up to `maxRetries` times (default 1), unless the caller's abort signal has fired. Inside `RagPipeline`, this error does not fail the search: the generated filter is dropped, a warning is logged, and `generatedFilterStatus` is `"error"`. See [Metadata catalog](/reference/metadata-catalog).

## FilterModelResponseError

Module: `src/adapters/OpenAiCompatibleFilterModel.ts`.

Thrown when the endpoint returns a successful status but the body is not the expected `{ "filter": ... }` JSON. Messages (after the `Filter model response error: ` prefix):

- `` response is missing `choices[0].message.content` ``
- `message content is not valid JSON`
- `` message content has no `filter` field ``

Fields: `message`, `name`.

Retry: no, and the filter model does not retry it. Inside `RagPipeline` it is handled like `FilterModelApiError`: the search continues without a generated filter.

## Other errors

These are thrown as plain `Error` (or `AggregateError`), so match them by message or by where they occur.

| Thrown by | When | Message starts with |
|-----------|------|---------------------|
| `RagPipeline.search` | Neither `language` nor a single-entry `languages` is set. | `RagPipeline.search requires an explicit query language` |
| `RagPipeline.search` | `autoFilter: true` without both `filterModel` and `metadataCatalog`. | `autoFilter requires both` |
| `new RagPipeline` | `filterTimeoutMs` is negative, non-finite, or above 2147483647. | `filterTimeoutMs must be` |
| `new RagPipeline` | A `filterLimits` value is not a positive integer. | `filterLimits.<name> must be a positive integer` |
| `RagIndexer.index` | The embedder returned a different number of vectors than chunks. | `Embedder returned` |
| `PostgresRagDatabase.hybridSearch` | One or more search legs failed. Thrown as `AggregateError` after all three legs settle; `errors` holds each leg's original error. | `hybridSearch: <n> of 3 search legs failed` |
| `new PostgresRagDatabase` | `ivfflatProbes` is not a positive integer (`0`, negative, a fraction or `NaN`), `ivfflatIterativeScan` is not `"off"` or `"relaxed_order"`, or `ivfflatMaxProbes` is not a positive integer. | `ivfflatProbes must be a positive integer` / `ivfflatIterativeScan must be` / `ivfflatMaxProbes must be` |
| `buildFilters` | A `sourceTypes`, `sourceIds` or `languages` value contains a comma. Each search leg calls `buildFilters` inside its own connection callback, so through `RagPipeline.search` or `PostgresRagDatabase.hybridSearch` this error arrives wrapped in the `AggregateError` above (one entry per failing leg). | `sourceTypes filter values must not contain a comma` (or `sourceIds`, `languages`) |
| `new Chunker` | `tokenLimit` or `chunkSize` is not a positive number. | `Chunker tokenLimit must be` / `Chunker chunkSize must be` |
| `new OpenAiCompatibleEmbedder` | `batchSize` or `concurrency` is not a positive number. | `OpenAiCompatibleEmbedder batchSize must be` / `... concurrency must be` |
| `new OpenAiCompatibleFilterModel` | `maxTokens` is set and not a positive integer. | `OpenAiCompatibleFilterModel: maxTokens must be` |
| `CachingMetadataCatalog.register` | A registry key is invalid. | `Invalid registry keys:` |
| `ragMigrate` | The SQL directory (`sqlDir`, or the package's own `sql/` directory when `sqlDir` is omitted) does not exist. Version 0.6.0 and earlier can't locate the directory when installed as a package; pass `sqlDir` on those versions (see [Migrations](/reference/migrations#sql-directory)). | `ragMigrate: SQL directory not found at <path>` |
| `serializeAttributes` | A decimal entry's `v` is not a decimal string. | `decimal entry` |

Database driver errors (for example a dimension mismatch on insert, a missing extension, or an RLS violation) propagate unchanged from your `SqlClient`.
