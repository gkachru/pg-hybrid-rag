# Tutorials

Tutorials are lessons. Each one takes you from an empty folder to a working result, one step
at a time, and explains just enough to keep you moving. Follow them in order.

| Tutorial | You will | Time |
|---|---|---|
| [Build your first hybrid search](/tutorials/getting-started) | Run PostgreSQL and an embedding server locally, create the schema, index six articles and search them. | About 20 minutes |
| [Filter results with metadata](/tutorials/metadata-filters) | Attach typed attributes to the articles, filter searches by category, date and plan, and inspect the tenant's metadata catalog. | About 15 minutes |

Both tutorials run entirely on your machine with Docker or Podman. You don't need an API key.

When you've finished, the [how-to guides](/how-to/) cover the tasks you'll meet when you use
the library in your own application.
